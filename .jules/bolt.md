## 2024-06-25 - Recharts Object References & Performance
**Learning:** In Next.js/React applications using Recharts, passing inline objects like `margin={{ top: 20, right: 30, left: 20, bottom: 5 }}` to Recharts components (like `BarChart`) causes the library to perform expensive full SVG recalculations and layout thrashing on every render due to failed reference equality checks on the new object. Similarly, dynamically generated arrays (like `quizData` or `heatmapData` inside component bodies) trigger the same behavior.
**Action:** Extract static Recharts configuration objects (like `margin`) outside of the component body. Wrap dynamically generated data arrays passed to Recharts with `useMemo` to maintain reference equality across renders unless dependencies change. Additionally, ensure custom shape or label content explicitly coerces geometric props (x, y, width, height) to `Number` to satisfy strict TypeScript validation, as Recharts may pass them as strings or undefined.
