## 2024-11-23 - Recharts Optimization\n**Learning:** Recharts triggers expensive full SVG recalculations on every render when non-primitives like arrays and objects are used as chart props without reference equality preservation.\n**Action:** Always wrap Recharts dynamically generated arrays/objects with `useMemo` and extract static configuration objects (like inline `margin` configurations) outside of the component body to maintain reference equality.
