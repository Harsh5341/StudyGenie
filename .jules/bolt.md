## 2024-03-09 - [Isolating Heavy Components from Root State Thrashing]
**Learning:** In Next.js App Router applications, when a high-level component (like `StudyGenieApp`) holds state that updates frequently (e.g., uncontrolled input lifts on every keystroke, or continuous chat history updates), it triggers a full tree re-render. This causes severe performance degradation if the tree contains heavy UI components (e.g., Recharts, or deeply nested content). Directly debouncing the root state update can introduce race conditions and UX bugs if users interact with other parts of the UI before the debounce flushes.
**Action:** Instead of complex debouncing at the root level, use `React.memo` on the heavy child components (like `ProgressDashboard`, `InteractiveLearning`) and `React.useCallback` for their event handlers. This isolates the expensive rendering work, allowing the root state to thrash naturally (to support responsive elements like the AI teacher) while preventing unnecessary cascading re-renders across the rest of the application.
