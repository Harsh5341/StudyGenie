## 2024-05-18 - Prevent Recharts Unnecessary Re-renders
**Learning:** Recharts components (like `BarChart`) can suffer from layout thrashing and unnecessary re-evaluations if their configuration objects (e.g., `margin`) are passed as inline objects inside the functional component, or if the `data` arrays/objects are recalculated on every render without referential equality. Additionally, geometric props passed to Recharts `<Label>` may be strings, requiring strict type coercion for type safety.
**Action:** Always extract static configuration objects outside of React components or use `useMemo` for dynamically generated data arrays/objects passed to Recharts to maintain reference equality. Always safely coerce string-based layout props (`x`, `y`, `width`, `height`) to numbers in Recharts components.
