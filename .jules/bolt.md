## 2025-03-14 - Parallelize Promise execution in Server Actions
**Learning:** Sequential await calls in Next.js Server Actions (like translating complex objects property-by-property) cause severe waterfall delays, increasing latency significantly. The `translateContent` function in `src/app/actions.ts` was waiting for `summary`, then `studyPlan`, then mapping over `quizzes` sequentially.
**Action:** Always group independent asynchronous operations using `Promise.all`. When mapping over arrays of objects that require multiple async property derivations, use nested `Promise.all` calls (e.g., awaiting the `question`, `options`, `correctAnswer`, and `topic` simultaneously for a single quiz object). This dramatically reduces total execution time without changing functionality.
