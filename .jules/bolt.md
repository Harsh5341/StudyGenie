## 2024-03-24 - Recharts Data Reference Equality
**Learning:** Recharts forces costly SVG layout recalculations when data prop references change. Because `quizData` and `heatmapData` were constructed inline on every render inside `ProgressDashboard`, Recharts would do a full teardown and redraw of charts even if the parent re-rendered for an unrelated state change. Moreover, when fixing TS errors for Recharts `Label` custom geometry props (`x`, `y`, `width`, `height`), wrapping variables with inline `typeof x === 'number' ? x : 0` drastically impacted code readability.
**Action:** Use `React.useMemo` for dynamically generated Recharts data props to preserve reference equality. Instead of inline `typeof` checks for geometric props, safely coerce potentially undefined Recharts `number | string` types to numbers using `Number(val || 0)` for cleaner and more readable math. Also, avoid wrapping simple arithmetic computations on primitive values (like `percentage`) in `useMemo`, as the hook invocation overhead outweighs the calculation cost.
