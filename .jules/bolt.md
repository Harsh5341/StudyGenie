## 2025-02-23 - Recharts Type Safety in ProgressDashboard
**Learning:** In Next.js with strictly configured Recharts, geometric properties like `x`, `y`, `width`, and `height` within Recharts' custom label renderers are typed as `string | number | undefined`. Mathematical operations directly on these properties throw build-time type errors. Additionally, extracting static configs (`margin`) and `useMemo`-wrapping dynamically generated object arrays passed to charting properties prevents layout thrashing on every render.
**Action:** When working with Recharts custom label components, ensure you destructure and explicitly coerce these coordinates (`Number(x) || 0`) prior to utilizing them in SVG rendering or calculations. Furthermore, extract configurations like `margin` out of React render scope and memoize dynamically built chart `data` props.
