## 2024-11-20 - [Recharts Reference Equality and Layout Thrashing]
**Learning:** Recharts triggers highly expensive full SVG recalculations and layout thrashing if the `data` arrays or configuration objects (like `margin`) lose reference equality between renders, even if the data itself is conceptually identical. Additionally, custom component geometric props in Recharts (like `x`, `y`, `width`, `height` in a `Label`) are typed loosely and can be passed as strings or undefined, leading to arithmetic/NaN errors if not explicitly coerced.
**Action:** When working with Recharts, always wrap dynamically generated arrays passed to `data` with `useMemo`, extract static objects (like `margin={{...}}`) outside of the component body, and safely coerce geometric props to `Number` before performing arithmetic.
