## 2024-05-24 - React Performance in Recharts Components
**Learning:** In this project, there's a pattern of rendering Recharts components with arrays generated dynamically in the component body (e.g. `quizData` and `heatmapData` in `ProgressDashboard`). Recharts can be sensitive to reference equality for its `data` prop, leading to unnecessary re-renders of the entire SVG when its parent component re-renders (even for unrelated state changes).
**Action:** When passing arrays or objects generated within the component to Recharts `BarChart` or `LineChart` data props, wrap their generation in `React.useMemo` to preserve reference equality and prevent unnecessary, expensive layout calculations on every render. Make sure to type-guard Recharts custom render functions correctly to pass strict TypeScript checks as their geometric properties might be typed as `number | string` or `undefined`.
