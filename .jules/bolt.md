
## 2024-11-21 - Recharts Component Re-rendering Optimization
**Learning:** Recharts components are highly sensitive to prop object reference changes. Inline data arrays and inline margin configuration objects passed directly to Recharts components (e.g., `margin={{ top: 20... }}`) cause unnecessary full SVG recalculations and layout thrashing on every React render cycle. Furthermore, geometric props (`x`, `y`, `width`, `height`) within custom Recharts `<Label>` rendering can sometimes be passed as strings or `undefined`, leading to subtle runtime bugs or strict typing failures if not carefully coerced to numbers.
**Action:** When working with Recharts, always extract static configuration objects (like `margin`) outside of the component body to maintain stable references. For dynamic data dependencies (`data={...}`), ensure they are wrapped with `useMemo`. Finally, enforce explicit type casting (`Number()`) for Recharts geometric props within custom label renderers to guarantee arithmetic safety.
