## 2024-05-24 - Recharts Strict Type Requirements and Memoization
**Learning:** Recharts can sometimes pass string or undefined values for geometric properties (like x, y, width, height) to custom components like `<Label content={...} />`. These properties must be explicitly coerced to numbers before performing arithmetic operations to satisfy strict TypeScript validation and avoid runtime errors. Additionally, dynamically created arrays passed to the `data` prop and inline configuration objects like `margin={{...}}` cause expensive full SVG recalculations on every render and should be memoized or extracted.
**Action:** Always wrap Recharts `data` arrays in `useMemo`, extract inline configuration objects outside the component body, and ensure explicit type checks or coercion to `number` when performing arithmetic on Recharts geometric properties in custom render functions.
