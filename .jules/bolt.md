## 2024-05-24 - Recharts Custom Label Typescript Errors & Layout Thrashing
**Learning:** When passing dynamically generated arrays or objects to Recharts components (e.g., `<BarChart data={...}>`), they must be wrapped in `useMemo`. Recharts performs expensive, full SVG recalculations if the array reference changes on every render. Additionally, geometric props (`x`, `y`, `width`, `height`) passed to custom Recharts `<Label>` functions can sometimes be `undefined` or string values during the rendering lifecycle, leading to strict TypeScript validation errors (`npm run typecheck`) and runtime arithmetic errors (`NaN`) if not handled explicitly.
**Action:** Always wrap dynamically generated Recharts data arrays in `useMemo`. When implementing custom Recharts labels, explicitly cast geometric props (`Number(x || 0)`) to satisfy TypeScript and prevent runtime math errors.
