## 2026-04-09 - Recharts Context Recalculation Pattern
**Learning:** Recharts components are incredibly sensitive to reference equality for their configuration props like `margin` objects, and passing inline arrays or mapped data forces expensive SVG recalculations across the whole Recharts DOM tree on every single render. Additionally, the `<Label>` sub-component's geometric props (x, y, width, height) are frequently passed as `string | number`, leading to subtle TypeScript arithmetic errors or string-concatenation bugs if not explicitly coerced.
**Action:** Always extract static Recharts config objects outside of the React component body to preserve reference equality. Wrap dynamically generated chart data arrays in `useMemo`. Always safely coerce geometric props provided by Recharts custom content renderers into Numbers before performing math.
